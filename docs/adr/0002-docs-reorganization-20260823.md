# 背景与问题

2026-08-23 仓库文档曾从根目录散落状态归入 `docs/` 分类结构（`docs/project/`、`docs/plans/`、`docs/reports/`、`docs/_devarchive/`）。
家族规范审计（Phase A/B）发现此后大量 AGENTS.md / README.md 链接仍指向旧位置，造成死链；本次补记为 ADR 固化该决策。

# 决策

- `docs/project/`：需求(PRD)、架构、API、技术选型、设计上下文。
- `docs/plans/`：实施计划、路线图、指南、待办。
- `docs/reports/`：各类审计/评测报告。
- `docs/_devarchive/`：归档（只新增、不修改）。
- 新增/移动 md 必须同步 `docs/整理记录_20260823.md` 的「旧路径 → 新路径」映射。

# 实施影响

- `docs/` 目录（除 7 个已跟踪文件外）当前未纳入 git 跟踪 → 本目录及 `<docs>/plans` 等均为**本地文档，未随仓库发布**（家族 C0 决策：标注而非入库）。

# 可回滚路径与待验证项

- 纯文档目录决策；回滚即按映射表恢复路径。
- 待验证：审计器死链 0；`docs/整理记录_20260823.md` 映射与磁盘一致。
