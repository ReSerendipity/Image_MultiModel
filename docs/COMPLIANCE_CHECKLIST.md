# Image MultiModel 对外服务合规检查清单（Compliance Checklist）

> 适用场景：将服务**公开部署**（公网服务器、对外开放访问）之前逐项检查。
> 纯本地个人使用（127.0.0.1 自用）不触发下列监管义务，本清单可跳过。
> 最后更新：2026-08-12

## 0. 服务形态判断

| 部署形态 | 是否触发 |
|---|---|
| 本机 127.0.0.1 自用 | ❌ 不触发 |
| 局域网小范围自用 | ⚠️ 边界情形，保持内网 + 鉴权 |
| 公网 / 对外开放 API / 面向公众 Web 服务 | ✅ 触发，按下表执行 |

## 1. 对外部署前检查项

| # | 事项 | 说明 | 状态 |
|---|---|---|---|
| 1 | 算法备案评估 | 图像生成属深度合成技术（图像生成类）。具有舆论属性或社会动员能力的深度合成服务提供者依《互联网信息服务深度合成管理规定》第十九条履行算法备案；是否触发取决于服务形态，部署前向属地网信部门咨询或通过算法备案系统评估 | ☐ |
| 2 | 安全评估 | 依《生成式人工智能服务管理暂行办法》第十七条，具有舆论属性或社会动员能力的生成式 AI 服务须开展安全评估 | ☐ |
| 3 | 备案主体资质 | 以服务提供主体名义办理（企业/个人），提前准备主体、服务、算法信息 | ☐ |
| 4 | AI 内容标识 | 输出图片已内嵌 DCT 溯源水印（v2 签名版，隐式溯源）；对外服务还应：a) 页面/输出界面显示"AI 生成"显式标识；b) 文件元数据写入标识字段（对齐《人工智能生成合成内容标识办法》及 GB 45438-2025，当前为增强项） | ☐ |
| 5 | 内容管理 | 提示词过滤与生成内容审核，禁止生成/传播违法信息（淫秽色情、暴力恐怖等）；建立举报处理流程。**公开仓库与分发物零容忍成人内容（违规内容）（已清理，含历史）** | ☐ |
| 6 | 用户协议 | 明确生成内容权责、禁止用途（侵权、诈骗、虚假信息） | ☐ |
| 7 | 个人信息 | 上传图片可能含人脸等个人信息：告知同意、及时删除、隐私政策公开 | ☐ |
| 8 | 访问控制 | 公网部署必须鉴权（API Key/账号）；确认 CORS 仅允许预期来源（默认仅 127.0.0.1） | ☐ |
| 9 | 密钥保护 | `.watermark_key` 仅存签发机器，服务器用环境变量注入；打包分发必须排除 | ☐ |
| 10 | 日志与溯源 | 保留任务日志（输入哈希、时间、账号）配合监管与侵权溯源 | ☐ |
| 11 | 备案后义务 | 变更（停止/主体/算法升级）及时办理变更/注销；配合监督检查 | ☐ |

## 2. 分发/便携包检查项

| # | 事项 | 说明 | 状态 |
|---|---|---|---|
| 1 | 模型许可矩阵 | 商用发行物仅内嵌 Apache-2.0 权重（Z-Image Turbo / SeedVR2）；FLUX.2 系（NC）不得内嵌，由用户自行下载 | ☐ |
| 2 | 密钥排除 | 打包时排除 `.watermark_key` | ☐ |
| 3 | 署名保留 | Apache 2.0 第 4 条：保留版权声明、LICENSE、NOTICE | ☐ |
| 4 | 内容干净 | 默认工作流无成人/违法内容（当前已净化，git 历史已重写） | ☐ |

*本清单为初稿参考，不构成正式法律意见；具体备案与监管要求以监管机构最新口径为准。*
