# 桌面分发分层定案（P1-3.1，2026-09-10）

> 依据：《桌面应用分发全流程指南》（报告1）分层设计；执行人：MainAgent 全自主，决策留痕于《执行对照表》。

## 1. 分层总览

| 层 | 内容 | 体积量级 | 分发方式 | 更新方式 |
|---|---|---|---|---|
| L1 壳层 | Tauri v2 壳（`desktop/src-tauri` → `ImageMultiModel.exe`） | ~10–20 MB | NSIS 安装器 | 安装器重装（壳自身不走增量） |
| L2 应用代码 | 项目根 Python 代码（`app/integrated_app`、`config.yaml`、`bin/`、`scripts/`、`static/`、`templates/`、`requirements*.txt`、`SECURITY.md` 等） | ~10–50 MB | 随安装器首发 / 增量包 | **增量更新（app-vX.Y.Z.zip + SHA256 + 清单签名）** |
| L3 运行时 | 侧载 Python 3.12 便携版（`runtime/`） | ~100–200 MB | 随安装器首发 / 整包分卷 | 不增量（随整包版本演进） |
| L4 计算依赖 | torch / diffusers / onnxruntime 等 pip 依赖（装入 `runtime/Lib/site-packages`） | ~3–6 GB | 整包分卷（≤900MB/卷） | 不增量（随整包版本演进） |
| L5 模型 | `model/`、`pretrained_models/` 权重 | ~数 GB | 整包分卷 / 用户按需下载 | 不增量（独立校验） |

## 2. 目录布局（安装后）

```
<安装目录>/
├─ ImageMultiModel.exe        # L1 壳
├─ app/                       # L2 应用代码（增量更新换载对象）
│  ├─ integrated_app/         #   后端包（app_server、security/ 等）
│  ├─ config.yaml             #   用户可改（换载时保留）
│  ├─ .watermark_key          #   本机水印密钥（换载时保留）
│  ├─ bin/ scripts/ static/ templates/ requirements*.txt ...
│  └─ version.json            #   发布时生成（增量更新版本依据）
├─ runtime/                   # L3 运行时 + L4 依赖（侧载 Python）
│  ├─ python.exe
│  └─ Lib/site-packages/...
├─ model/ pretrained_models/  # L5 模型（PRESERVE_TOP_DIRS 保留）
├─ data/                      # 用户数据（PRESERVE_TOP_DIRS 保留）
└─ logs/                      # 运行日志（PRESERVE_TOP_DIRS 保留）
```

## 3. 增量更新范围与保留策略

- **增量包**：仅 L2 `app/` 内容（zip 根即 app/ 内容），assets 命名 `app-v{version}.zip` + `.sha256`。
- **换载保留**（updater.rs `PRESERVE_TOP_DIRS` / `PRESERVE_ROOT_FILES`）：
  - 顶层目录：`runtime/`、`model/`、`data/`、`logs/`（增量包不含，换载前从旧 `app/` 补入 `app.new/`）。
  - 根级文件：`config.yaml`（用户修改）、`.watermark_key`（本机溯源密钥）。
- **版本号**：`config.yaml version` 为权威位（用户裁决 A），发布时写入 `app/version.json`；`minimum_shell_version` 约束壳兼容性。

## 4. 发布物清单

| 产物 | 生成方式 | 校验 |
|---|---|---|
| `ImageMultiModel-{ver}-setup.exe` | tauri build + NSIS（`desktop/installer/*.nsi`） | SHA256SUMS |
| `app-v{ver}.zip` | `scripts/package_app.py`（打包 L2） | SHA256 + 清单签名 |
| `app-v{ver}.zip.sha256` | 同 zip 生成 | 逐字节校验 |
| `分卷 z01..zNN` | `scripts/split_release_volumes.py`（7za，≤900MB/卷） | SHA256SUMS 全覆 |
| `shell-update.json` | release 描述 | updater 拉取 |

## 5. 受限项

- 当前仓库 `pretrained_models/` 为空、`model/` 仅占位符：**真实模型分卷验证受限**，以测试数据验证分卷脚本逻辑（P1-3.4 验收降级说明）。
- 运行时侧载（runtime/）由发布流程下载 WinPython 便携版组装，本仓库不提交。
