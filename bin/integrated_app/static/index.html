Image MultiModel
Z-Image Turbo 图像生成平台

面向本地 AI 图像生成的工作台：Z-Image-Turbo 原生引擎进程内推理，LoRA 六层叠加、SeedVR2 超分、Eses 双图对比与显存预留，以对话式主界面屏蔽工作流复杂度。

作者ReSerendipity
当前版本v1.0.0
协议Apache 2.0
GitHub 仓库
▦原生引擎Z-Image-Turbo，进程内推理
▥六层 LoRA串联叠加 id=16→21，禁用自动重连
◔SeedVR2 超分ema_vae + 3B DiT，多档最短边
◫双图对比Eses h/v/s 拼接，直观比对
◳显存预留ReservedVRAM 保护生成稳定
◧本地运行进程内原生引擎，数据不出机器
