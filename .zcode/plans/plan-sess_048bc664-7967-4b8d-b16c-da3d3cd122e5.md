# 实施计划：三项改进任务

## 一、DCT 水印性能优化（GPU 加速）

### 现状分析
- `watermark.py` 是纯 numpy 实现（约 200 行），用预计算的 8×8 DCT-II 基矩阵做矩阵乘法
- 每次生成一张图就调一次 `_embed_watermark()`：PIL 打开 → numpy float64 → 逐块 DCT/IDCT → 写回 PNG
- 无 cupy/cuda，当前在 CPU 上运行

### 方案：引入 cupy 实现 GPU 加速

**新增文件**：`bin/integrated_app/watermark_gpu.py`（备用层）
```python
import cupy as cp  # Optional dependency
from . import watermark as cpu_wm

# GPU 版 embed_watermark():
# - 将整幅图像一次性搬到 GPU
# - 向量化计算所有块的 DCT（batch matmul 替代循环）
# - IDCT 后搬回 CPU 写 PNG
# 
# fallback: 如果 cupy 不可用 → 自动回退到现有 CPU 实现
```

**改动策略**（优雅降级）：
1. 在 `watermark.py` 的 `embed_watermark()` 入口检测 cupy 是否可用
2. 如果 `import cupy` 成功 → 走 GPU 路径
3. 如果失败 → 继续原有 CPU 代码路径（完全不变）
4. 添加 `requirements.txt` 可选依赖：`cupy-cuda12x>=13.0.0`（或 `cupy-cuda11x`，根据安装环境自动选择）

**预期性能提升**：
- 单次图片水印嵌入：从 ~50ms 降到 ~5ms（cuBLAS 批量 matmul vs 串行 numpy 循环）
- 大批量生成时总耗时减少不明显（瓶颈在模型推理而非水印），但对用户体验有改善

## 二、SeedVR2 超分集成（diffusers_engine 自动调用）

### 现状分析
- SeedVR2-Toolkit 是独立项目（Apache-2.0），提供 `SeedVR2Engine` 类
- 引擎接口基于**文件路径**（非 PIL.Image 对象）：`infer_image(image_path, output_dir, config)`
- 内部使用自己的 DiT/VAE 管线，与 diffusers ZImagePipeline 完全独立
- `diffusers_engine.py` 中预留了 `_apply_seedvr2_upscale()` 方法但仅返回原图（ImportError catch 直接放行）

### 方案：创建集成模块自动管理 SeedVR2 生命周期

**新建文件**：`bin/integrated_app/services/seedvr2_service.py`
```python
"""SeedVR2 超分服务 —— 集成 Image_MultiModel 与 SeedVR2-Toolkit"""

from __future__ import annotations
from pathlib import Path
from typing import Any

import torch

# 懒导入模式：不安装 SeedVR2-Toolkit 时优雅降级
SEEDVR2_AVAILABLE = False
try:
    from bin.integrated_app.engines.seedvr2_engine import SeedVR2Engine
    SEEDVR2_AVAILABLE = True
except ImportError:
    pass


class SeedVR2Service:
    """线程安全的 SeedVR2 单例管理器"""
    
    def __init__(self) -> None:
        self._engine: SeedVR2Engine | None = None
        self._loaded = False
    
    @property
    def available(self) -> bool:
        return SEEDVR2_AVAILABLE
    
    async def ensure_loaded(
        self,
        model_size: str = "3b",
        precision: str = "fp16",
        project_root: str = "",
    ) -> None:
        """首次使用时加载模型（懒加载，不影响启动时间）"""
        if self._loaded or not SEEDVR2_AVAILABLE:
            return
        
        # 构建配置（参考 TTS_MultiModel 的 engine_registry 注册模式）
        config = {
            "model": {
                "models_root": f"{project_root}/pretrained_models/SeedVR2/{model_size}",
            },
        }
        
        self._engine = SeedVR2Engine(config=config)
        await self._engine.load_model(model_size=model_size, precision=precision)
        self._loaded = True
    
    async def upscale_single(
        self,
        image_path: str,
        target_resolution: int = 2048,
        color_correction: str = "lab",
        seed: int = -1,
    ) -> str:
        """超分单张图片，返回输出路径"""
        if not self._loaded or not SEEDVR2_AVAILABLE:
            raise RuntimeError("SeedVR2 not available")
        
        result = await self._engine.infer_image(
            image_path=image_path,
            output_dir=f"{image_path}_sr_out",
            config=ImageInferenceConfig(
                resolution=target_resolution,
                seed=seed,
                color_correction=color_correction,
            ),
        )
        return result.output_path
    
    async def unload(self) -> None:
        """释放 SeedVR2 显存"""
        if self._engine:
            await self._engine.unload_model()
            self._engine = None
            self._loaded = False
            torch.cuda.empty_cache()
```

**修改文件**：`bin/integrated_app/native/diffusers_engine.py`
- 重构 `_apply_seedvr2_upscale()` 调用 `SeedVR2Service.ensure_loaded()` + `upscale_single()`
- 在 `unload()` 中也卸载 SeedVR2（避免显存泄漏）
- 不再需要用户手动安装任何包（提示清晰但不会阻塞）

**用户操作**（仅需一次）：
```bash
# 1. 安装模型权重到 portable 目录
huggingface-cli download ByteDance/SeedVR2 --local-dir pretrained_models/SeedVR2/7b

# 2. 之后引擎自动生成时会按需加载（懒加载，不影响冷启动）
```

### 方案 A：后端生成合成对比图（简单可靠）

**修改** `diffusers_engine.py` 的 `_save_outputs()`：
```python
def _save_outputs(self, images, config, seed):
    # ... 现有逻辑 ...
    outputs = []
    for idx, img in enumerate(images):
        # 保存原始图
        outputs.append(self._save_one(img, task_id, seed, idx, "original"))
        
        # 如果有对比需求（两张以上的 batch 才做对比）
        if config.eses_enable and len(images) > 1:
            compare_img = self._generate_ese_compare(
                images[0], images[idx % len(images)], 
                config.eses_compare_axis
            )
            outputs.append(self._save_one(compare_img, task_id, seed, idx, "compare"))
    
    return outputs
```

**新增方法** `_generate_ese_compare()`：
```python
@staticmethod
def _generate_ese_compare(img_a, img_b, axis="horizontal"):
    """生成 EsEs 对比图并返回 PIL.Image
    
    - horizontal: 左 A / 右 B（垂直分割线在中间）
    - vertical: 上 A / 下 B（水平分割线在中间）  
    - slider: 中间放一个拖拽滑块（前端 CSS 实现，后端只给左右各半）
    """
    from ..native.compares import diff_mask
    import cv2 as _cv  # 用于绘制分割线和标签
    
    # resize 两张图到相同尺寸
    max_w = max(img_a.width, img_b.width)
    max_h = max(img_a.height, img_b.height)
    img_a = img_a.resize((max_w, max_h))
    img_b = img_b.resize((max_w, max_h))
    
    arr_a = np.array(img_a)
    arr_b = np.array(img_b)
    
    if axis == "horizontal":
        combined = np.hstack([arr_a, arr_b])
        # 中间加一条白色分割线 + 标签
        line_x = max_w // 2
        combined[:, line_x] = [255, 255, 255]  # 白线
    elif axis == "vertical":
        combined = np.vstack([arr_a, arr_b])
        line_y = max_h // 2
        combined[line_y, :] = [255, 255, 255]
    
    return PIL.Image.fromarray(combined)
```
